# Architecture

## Request flow

1. React/Vite calls the Express API.
2. The API validates the question and selected language.
3. For a non-English question, Gemini can translate the question into concise English retrieval terms only. This step does not answer the question or create source content.
4. Retrieval first attempts MongoDB Atlas Vector Search when Atlas and Gemini embeddings are configured and the index is queryable.
5. If Atlas is unavailable or the index is not ready, deterministic local keyword retrieval searches the checked-in JSON corpus.
6. The API sends only retrieved passages to Gemini for a plain-language explanation. Citations are built by the API from the retrieved source records, not generated by Gemini.
7. The UI displays extracted source text, Article identifier, PDF page range, source edition and a human-review status.

## Constitution corpus

`apps/api/src/generated-corpus.json` is generated from the official Legislative Department PDF. It stores source metadata and hash, Article records, retrieval passages, page ranges, clause-reference hints and a content review status. The current source edition is dated 10 September 2026. The checked-in corpus contains 481 Article records, all 12 Schedules, all 3 Appendices and 2,165 retrieval chunks. The extraction is machine-generated and is not human-verified. Do not mark it published until a reviewer has checked source fidelity and legal content.

The parser is `tools/import-constitution.mjs`. The Windows wrapper `tools/extract-constitution.ps1` uses Poppler `pdftotext -layout`; it does not require Python. The app does not need to run the importer during normal development because the generated corpus is committed.

## Atlas Vector Search

- Collection: `samvidhan_ai.constitutional_chunks` by default.
- Embedding model: `gemini-embedding-001`.
- Task types: `RETRIEVAL_DOCUMENT` for source chunks and `RETRIEVAL_QUERY` for questions.
- Dimensions: 768, normalized before storage.
- Vector index: `constitution_vector_index`, configured by `apps/api/config-constitution-vector-index.json`.
- Source version is a filter field so retrieval does not mix editions.
- `apps/api/scripts/index-constitution.mjs` skips unchanged content hashes and upserts changed passages.

MongoDB Atlas Vector Search is opt-in through `ATLAS_VECTOR_SEARCH_ENABLED=true`; a local MongoDB URI alone never activates it. Without Atlas, the API uses the same checked-in corpus with local keyword scoring. It never pretends that an unavailable Atlas index returned semantic results.

## Trust and safety boundaries

- Retrieved source passages are data, not instructions. Prompt-injection text inside a source cannot change system behavior.
- Gemini cannot create or alter citations. Citation identifiers and page links are generated from corpus metadata.
- The model is instructed not to invent Article references, cases or quotations.
- Insufficient retrieval returns an explicit insufficient-sources response.
- Source text, AI explanation, generated translation and human-reviewed content are separate concepts and must be labelled separately.
